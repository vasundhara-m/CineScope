# CineScope

CineScope is a React movie discovery app for searching and browsing titles using the public TVmaze API.

## Features

- Search movies and shows
- Browse featured titles
- Filter by category
- View ratings, genres, and release years
- Open detailed movie information
- Responsive design
- Loading, error, and empty states

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```
